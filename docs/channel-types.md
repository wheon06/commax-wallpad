# 전등·배기 유형 변경

코맥스 통신에서 `dev=light`라고 내려와도 실제 장치는 환풍기일 수 있습니다. API 채널과 Apple 홈의 표시 유형은 구분합니다.

| 코맥스 연동 목록 | HA 유형 | Apple 홈 표시 |
|---|---|---|
| 전등 번호 | `light` | 전등 |
| 배기 번호 | `fan` | 팬 |

옵션 예시:

```text
변경 전: 전등 1-3,6 / 배기 7,8
변경 후: 전등 1-3   / 배기 6-8
```

저장 후 전등 6번은 제거되고 팬 6번이 생성됩니다. 같은 번호에 두 액세서리를 유지하지 않습니다. 삭제된 번호도 이 코맥스 설정 항목에 속한 엔티티만 정리합니다.

HomeKit Bridge를 다시 불러오세요. 브리지 필터가 특정 엔티티 ID만 포함한다면 이전 `light`를 빼고 새 `fan`을 선택합니다. 단순 이름 변경이나 아이콘 변경만으로 서비스 유형이 바뀌지는 않습니다.

HomeKit은 엔티티 ID를 액세서리 식별에 사용합니다. 유형 변경으로 `light.*`에서 `fan.*`로 바뀌면 새 액세서리로 처리될 수 있어 방·장면·자동화 재지정이 필요합니다. 전체 집이나 다른 브리지를 지울 필요는 없습니다. 캐시가 남을 경우 해당 액세서리 재설정부터 시도하고, 전체 브리지 삭제는 마지막에 선택하세요.

참고: [HomeKit Bridge 문서](https://www.home-assistant.io/integrations/homekit/#accessory-id)
